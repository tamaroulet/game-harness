# solve の入口と、解けない格子
マイルストーン: bench
タスク: P-03
要件: REQ-01, REQ-02, REQ-08

## What
- 入口は `from maze import solve`。`solve(grid)` は傾きの list か `None` を返す。傾きは 2 つの float の tuple で、どちらも絶対値 0.1 以下
- `grid` の検査は `simulate` と同じ範囲で、外れたら `ValueError`
- つながりは、`#` でないセルを上下左右（斜めは含まない）に辿って `S` から `G` に着けるかで決める。着けなければ `None`
- つながっている格子では、この What は `None` でない値（傾きの list）を返すところまでを受け持つ。その list が玉を `G` に運ぶことは、P-04 が確かめる

## 合格条件
- 変えるファイルは `maze/__init__.py`、`maze/solver.py` と `tests/test_maze_solve_basic.py`
- 試験は、壁で `S` と `G` が隔てられた格子（斜めにしかつながらない格子を含む）で `None`、つながる格子で list（各要素が長さ 2 の tuple で範囲内）、不正な格子で `ValueError` を確かめる。物理の実行は試験に入れない
