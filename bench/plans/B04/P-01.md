# simulate と入力の検査
マイルストーン: bench
タスク: P-01
要件: REQ-01, REQ-02, REQ-03, REQ-04, REQ-07

## What
- 入口は `domino.simulate(n, spacing, steps, origin=(0.0, 0.0), direction="+x")`。返り値は長さ `steps` の list で、各要素は長さ n の list、その要素は `pos`（3 個の float の list）と `tilt`（float）を持つ辞書。
- `spacing`・`origin`・`n`・`steps` の範囲の端（`n` の 2 と 12、`spacing` の 0.04 と 0.2、`steps` の 1 と 20000、`origin` の各要素の絶対値 1）は範囲の内として通す。端の外、`bool`、`nan`・`inf`、`n`・`steps` が整数でない値（2.0 のような float を含む）、`origin` が長さ 2 の list か tuple でないもの、4 つのどれでもない `direction` は `ValueError`。
- 置いた位置の確認は 1 歩目の状態で、`tilt` の許容を 0 番とそれ以外で分けて読む。床の確認は全歩の全板の `pos[2]` が 0 以上。
- `direction` は水平の 4 向きで、`-x`・`-y`・`+y` も 1 歩目の置いた位置の確認に含める。

## 合格条件
- 変えるファイルは `domino/__init__.py`、`domino/sim.py`、`tests/test_domino_simulate.py`。
- 試験は、範囲外の入力が `ValueError` になること、同じ引数 2 回で返り値が完全に一致すること、1 歩目の位置と傾きの許容、床の下に潜らないことを確かめる。steps は小さくして試験を短く保つ。
