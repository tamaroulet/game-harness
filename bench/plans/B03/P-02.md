# 減速・止まる・正面衝突・鏡
マイルストーン: bench
タスク: P-02
要件: REQ-05, REQ-06, REQ-07, REQ-10

## What
- 縁にも的球にも触れずに止まる打ち出しでは、`shot` の最後の手球の `pos` と `cue` の距離 d は 0.99·speed/1.5 ≤ d ≤ 1.01·speed/1.5（両端を含む）。`cue` から見たその向きと `angle` の差は 0.001 rad 以内
- どの `shot` も `steps` ≤ 3000 で、最後の状態でポケットに入っていない球の速さはどれも 0.001 未満
- 正面衝突は、2 つの中心の y が等しく、的球が手球の +x の側にあり、`angle` が 0 の打ち出し。2 つの中心の距離が 0.05 以下になった最初の歩を接触の始め、その後で 0.05 を超えた最初の歩を接触の終わりとする。接触の終わりの手球の速さは、始めの手球の速さの 0.2 倍以下。的球の速さは、始めの手球の速さの 0.75 倍以上 1.0 倍以下で、的球の `vel` の y の絶対値は 1e-6 以下
- 鏡（y）：`cue`・`target` の y の符号を反転し `angle` を −`angle` にした打ち出しの各歩で、`pos` と `vel` の y 成分は元の符号反転と 1e-6 以内で一致し、x 成分は元と 1e-6 以内で一致する。鏡（x）：`cue`・`target` の x の符号を反転し `angle` を 180 − `angle` にした打ち出しの各歩で、`pos` と `vel` の x 成分は元の符号反転と 1e-6 以内で一致し、y 成分は元と 1e-6 以内で一致する。どちらの鏡でも、各歩の `pocketed` は元と同じ
- 満たさない振る舞いがあれば `billiards/table.py` を直す
