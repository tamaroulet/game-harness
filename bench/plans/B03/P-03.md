# 縁の反発とポケット
マイルストーン: bench
タスク: P-03
要件: REQ-08, REQ-09

## What
- ポケットに入っていない球の中心は、どの歩でも |x| ≤ 0.49 かつ |y| ≤ 0.24
- 縁の反発：`angle` が 0 で、ほかの球に触れずに +x の縁に当たる手球について、中心の x が 0.47 以上になった最初の歩の 1 つ前の歩の速度の x を v1、その後で x が 0.47 未満に戻った最初の歩の速度の x を v2 とすると、−v2 ÷ v1 は 0.6 以上 1.0 以下。そのあいだのどの歩でも、中心の y と `cue` の y の差は 1e-6 以内。この y の条件は、この打ち出しに限る
- ポケット：球の中心が四隅のどれかから 0.05 以内（境界を含む）に入った最初の歩で、その球の `pocketed` は `True` になり、以後の歩で `pos` は変わらず `vel` は `[0.0, 0.0]`
- 直接打ち：隅 C から台の内側へ、x 軸と 35° 以上 55° 以下の角をなす直線の上で、C から距離 L（0.2 ≤ L ≤ 0.35）の点に手球を置き、C の向きに 0.8 ≤ speed ≤ 1.5 で打つ。的球はその直線から 0.1 m 以上離れた位置。このとき手球がポケットに入る
- 的球を介す打ち：同じ直線の上で、C から距離 L（0.15 ≤ L ≤ 0.25）の点に的球を、その 0.1 m 後ろ（C から遠い側）に手球を置き、C の向きに 1.0 ≤ speed ≤ 1.5 で打つ。このとき的球がポケットに入る

## 合格条件
- 変えるファイル：`billiards/table.py`、`tests/test_billiards_pocket.py`
- 試験は 4 つの隅のうち複数、上の範囲の端に近い値（角 35°・55°、L・speed の下限と上限）を含めて確かめる
