# ばねの鎖の入口と始めの状態
マイルストーン: bench
タスク: P-01
要件: REQ-01, REQ-03, REQ-04, REQ-05

## What
- 入口は `springchain.simulate(n, mass, stiffness, damping, steps, x0=None, v0=None)`。返り値は長さ `steps` の list で、各要素は `"x"`・`"v"` の 2 つの鍵を持つ辞書（値は n 個の float の list）。i 番目の要素は i＋1 歩目の後の状態
- `x0`・`v0` を省く（`None`）と、すべて 0 として扱う。`x0`・`v0` は list でも tuple でもよい
- 呼び出しごとに独立で、前の呼び出しの状態を引き継がない。同じ引数で呼べば、値はビット単位で同じ
- 範囲の内の引数だけを扱う（範囲の検査は P-02 が受け持つ）

## 合格条件
- 変えるファイル：`springchain/__init__.py`、`tests/test_springchain_basic.py`
- 試験は、返り値の長さと形、同じ引数で 2 回呼んだときのビット一致、1 歩目の状態の許容（REQ-04）、静止（REQ-05）を、n・mass・stiffness を変えた数通りで確かめる
