# エネルギー・減衰・固有振動の確かめ
マイルストーン: bench
タスク: P-03
要件: REQ-06, REQ-07, REQ-08, REQ-09

## What
- 状態のエネルギーは、課題の式（運動のエネルギーと、壁を含む n＋1 本のばねの弾性のエネルギー）で試験が計算する。始めのエネルギー E0 は `x0`・`v0` から同じ式で出す
- エネルギーの保存：`damping` ＝ 0 の入力だけで確かめる。5000 歩までのどの歩でも E は E0 の 0.97〜1.03 倍
- 減衰（E の減り）：`damping` が 0.1 以上 0.2 以下、`mass` が 0.1 以下（下限 0.05 まで）、`n` が 2 以上 6 以下で、E0 ＞ 0 の入力だけで確かめる。どの歩でも E ≤ 1.03·E0、5000 歩目の E ≤ 0.5·E0。この範囲の外の組は回さない
- 固有振動の周期：`damping` ＝ 0、`x0` ＝ A·s_p（0.005 ≤ A ≤ 0.03、1 ≤ p ≤ n）、`v0` はすべて 0 の入力だけで確かめる。N ＝ round(T/0.002) 歩目と H ＝ round(T/0.004) 歩目を、課題の許容（0.02·A）で確かめる（歩数は 1 始まりで、返り値の添字は歩数 − 1）。`damping` ＞ 0 では回さない
- ばねの間の減衰：`damping` が 0 より大きく 0.02 以下、`mass` が 0.1 以上 0.5 以下、`stiffness`/`mass` が 16 以上 25 以下、`x0` ＝ A·s_p（A は上と同じ範囲）、`v0` はすべて 0 の入力だけで確かめる。1000 歩目の E ÷ E0 と exp(−(damping/mass)·(ω_p/ω0)²·2) の比が 0.9〜1.1。この範囲の外の組は回さない
- 試験で合わない場合は、`simulate` の模型（減衰をばねに並べて付ける・自由度 1・接触なし）を直す。試験の範囲を広げて近似の外を確かめることはしない
