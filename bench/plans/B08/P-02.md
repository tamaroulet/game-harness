# 入力の範囲の検査
マイルストーン: bench
タスク: P-02
要件: REQ-02

## What
- 範囲の外の引数、数でない引数、`bool`、整数でない `n`・`steps` では、`simulate` は `ValueError` を投げる（`TypeError` などにしない）
- 範囲の端の値（`n` ＝ 2・12、`mass` ＝ 0.05・0.5、`stiffness`/`mass` ＝ 4・25、`damping` ＝ 0・0.2、`steps` ＝ 1・20000、`x0` の 0.03、`v0` の 1）は受け入れる。端のすぐ外は拒む
- `x0`・`v0` は `None`・長さ n の list・長さ n の tuple だけを受け入れる。長さが違う、ほかの型である、要素が nan・inf・数でない・`bool` である場合は拒む
- 検査は、物理の計算を始める前に終える

## 合格条件
- 変えるファイル：`springchain/__init__.py`、`tests/test_springchain_validation.py`
- 試験は、各引数について、端の内・端の外・型の違い・nan と inf・`bool` を確かめる。端の内の呼び出しでは、`steps` を小さくして時間を抑える
