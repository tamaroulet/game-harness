# 坂を登る車の模型と simulate の入口
マイルストーン: bench
タスク: P-01
要件: REQ-01, REQ-03, REQ-04, REQ-05

## What
- 入口は `hillcar.simulate(slope, torque, steps)`。`slope` は度、`torque` は N·m、`steps` は歩数。有効な引数のとき、長さ `steps` の list を返す。i 番目（0 起点）は i＋1 歩目の後の状態
- 各要素は `x`・`z`・`pitch`・`flipped` の 4 つの鍵だけを持つ辞書。`x`・`z`・`pitch` は float、`flipped` は bool。`pitch` は前（+x の側）が持ち上がる向きが正で、範囲は −π より大きく π 以下
- `flipped` は、車体の上向きの軸と面の法線 +z の内積が 0 未満になった歩から後はずっと True（内積が戻っても True のまま）。それまでは False
- 模型（MuJoCo 3.15.0、時間の刻み 0.002 s、1 歩 ＝ 1 刻み）：坂の面は z ＝ 0 の無限の平面で、登る向きが +x。坂の角 α（度）は重力 (−9.81·sin α, 0, −9.81·cos α) で表す。車体は 0.1 × 0.06 × 0.04 m・1.0 kg の直方体で、中心は始めに (0, 0, 0.1)、x 向きのスライド・z 向きのスライド・y 軸まわりの蝶番で x–z の面の中だけで動く。輪は半径 0.1 m・0.25 kg の中実の球が 2 つ。後輪の中心は車体の中心から (−0.05, 0.12, 0)、前輪は (+0.05, −0.12, 0)。どちらも y 軸まわりの蝶番で回り（減衰・摩擦・armature は 0）、始めは面にちょうど接する。トルク `torque`（N·m、正が +x へ進める向き）は後輪の蝶番だけに始めから終わりまで一定にかける（motor、gear 1）。面・車体・輪のすべての geom の摩擦は (1, 0.005, 0.0001)、`solref` は (0.004, 1)。ほかは MuJoCo の既定。範囲外の引数の扱いはこの What では決めない（別のタスクが受け持つ）
- 同じ引数で 2 回呼んだ返り値は、すべての値がビット単位で一致する（float は `struct` で詰めた並びなどで比べる）

## 合格条件
- 変えるファイルは `hillcar/__init__.py` と `tests/test_hillcar_sim.py`
- 試験は、返り値の形（長さ・鍵・型）、2 回呼びのビット一致、1 歩目の範囲、slope 0・torque 0 の静止（200 歩ほどの各歩）を確かめる
- 試験は、slope 0・torque 1.2 の 1000 歩で、どの歩でも pitch が −π より大きく π 以下であること、flipped が一度 True になったら以後 False に戻らないこと、最後の歩の flipped が True であることも確かめる
