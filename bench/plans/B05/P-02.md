# 立つかどうかの判定 stands
マイルストーン: bench
タスク: P-02
要件: REQ-01, REQ-02, REQ-03, REQ-05, REQ-06, REQ-08, REQ-10

## What

- `tower` パッケージから `stands(offsets)` を import できる。返り値は `bool`。入力の範囲は `simulate` の `offsets` と同じで、外れたら `ValueError`
- 定義は `simulate(offsets, 2000)` の最後の歩の、一番上の箱の z が置いた高さ 0.025 + 0.05·(k−1) の 0.95 倍以上のとき、かつそのときだけ `True`（ちょうど 0.95 倍は `True`）
- 立つ積み方（すべての j で d_j ≤ 0.04）では `True` で、2000 歩のどの歩でも各箱の中心は置いた位置から 0.005 m 以内。崩れる積み方（ある j で d_j ≥ 0.06）では `False`
- `offsets` の符号反転と、全体への同じ数の加算（範囲の内）で、`stands` の値は変わらず、`simulate` の x は反転・ずれに 1e-3 以内で従う
- 同じ引数で 2 回呼んだ返り値は同じ

## 合格条件

- 変えるファイルは `tower/` の下と `tests/test_tower_stands.py`
- 試験は k ＝ 1〜6 の立つ例と崩れる例（例：k ＝ 2 で offsets ＝ [0, 0.1] は d ＝ 0.1）、鏡と平行移動を確かめる。各 `stands` は 2000 歩なので、呼び出し回数を絞る
