# 積み木の塔のシミュレーション入口 simulate
マイルストーン: bench
タスク: P-01
要件: REQ-01, REQ-02, REQ-03, REQ-04, REQ-09

## What

- リポジトリの根の `tower` パッケージから `simulate(offsets, steps)` を import できる。返り値は長さ `steps` の list で、各要素は長さ k の list（下の箱から順）、その要素は `pos`（3 個の float の list）と `vel`（3 個の float の list）を持つ辞書
- `offsets` は list か tuple。長さ 1〜6、各要素は絶対値 0.5 以下の有限の数（`bool` と数でないものは外れ）、隣り合う差の絶対値は 0.1 以下。端の値（0.5、差 0.1、長さ 1 と 6）は受け入れ、`steps` は整数で 1〜20000（端は受け入れ、`bool` と整数でない数は外れ）。外れたら `ValueError`
- 同じ引数での 2 回の呼び出しは、返り値のすべての float がビット単位で同じ

## 合格条件

- 変えるファイルは `tower/` の下と `tests/test_tower_simulate.py`
- 試験は 1 歩目の位置、床の高さ、範囲外の入力、決定論を確かめる。長い歩数の試験は 2000 歩までにして、時間をかけすぎない
