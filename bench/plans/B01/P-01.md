# 玉転がしの土台：Game の入口・入力の検査・決定論・静止・盤の上の高さ
マイルストーン: bench
タスク: P-01
要件: REQ-01, REQ-02, REQ-03, REQ-04, REQ-07

## What

- リポジトリの根の `rollgame` パッケージから `from rollgame import Game` で `Game` を取れる。`Game()` は引数なしで呼べ、課題の模型の初めの状態（玉が盤に接して静止）の遊びを作る
- `Game.step(tx, ty)` は引数 2 つ（位置引数でもキーワードでも可）を取り、辞書を返す。辞書のキーは `pos`・`vel`・`outcome`。`pos` と `vel` は Python の `float` 3 個の `list`。この段では `outcome` は常に `None` でよい（終わりの判定は後の段で足す）
- 傾きは歩ごとに盤ではなく重力の向きで与える。課題の式の重力を、その歩の物理の前に設定する
- 入力の検査：`tx`・`ty` のどちらかが範囲の外（-0.2 未満、0.2 超）、`nan`・`inf`、数でないもの（文字列・`None`・`bool`）なら `ValueError`。検査は物理を 1 歩進める前に行い、不正な入力の `step` は遊びの状態を変えない。`int` と `float` の有限の数で範囲の中なら通る。境界の ±0.2 は通る
- 決定論：同じ入力の列を与えた別々の `Game` が返す辞書は、`pos`・`vel` の全要素がビット単位で等しい（乱数や時刻に依存しない）
- 物理は `mujoco` で計算し、課題の模型の寸法・質量・刻み 0.002 s・既定の接触の設定に従う

## 合格条件

- 変えるファイル：`rollgame/__init__.py`、`rollgame/game.py`、`tests/test_rollgame_core.py`
- 試験は `tests.test_rollgame_core` モジュール。入口の形、範囲の端と範囲の外・不正な型、2 つの `Game` の一致、傾き (0, 0) の 1000 歩での x・y のずれと `outcome`、盤の上（x・y がともに -0.45〜0.45）での z の範囲を確かめる
- 試験は 1000 歩程度までの短い走りだけを使い、実行を数秒に収める
