# 玉転がしの転がりと対称
マイルストーン: bench
タスク: P-02
要件: REQ-05, REQ-06

## What

- 傾き (0, 0) で 100 歩進めて落ち着かせた後、傾き (t, 0) を n 歩続ける。x の変化 Δx は `pos[0]` の差（続け始める直前と n 歩後）で測る。Δx は t と同符号（t > 0 なら Δx > 0、t < 0 なら Δx < 0）で、|Δx| は理論値 ½ · 9.81 · |sin t| · (0.002·n)² の 0.64 倍以上 0.80 倍以下
- 同じ n 歩での y の変化は絶対値で 0.001 m 未満
- 傾き (0, t) でも x と y を入れ替えて同じ振る舞いになる。t は 0.05 以上 0.2 以下の正負どちらも、n は 100 以上 180 以下
- 入力の列の各歩の (tx, ty) を (ty, tx) に替えた別の `Game` では、各歩の `pos`・`vel` の x と y が入れ替わった値（差は 1e-4 以内）になり、z は一致し、`outcome` の列も同じ
- この段は P-01 の `Game` の振る舞いの確認であり、入口の形は変えない

## 合格条件

- 変えるファイル：`rollgame/game.py`、`tests/test_rollgame_roll.py`
- 試験は `tests.test_rollgame_roll` モジュール。t と n の代表の組（正負の t、n の両端を含む）を x 向き・y 向きの両方で確かめ、対称の試験は x と y が異なる傾きを混ぜた入力の列を使う
- 試験の走りは 1 本あたり 300 歩以内に収める
