# 着地の点と床（landing）
マイルストーン: bench
タスク: P-02
要件: REQ-01, REQ-05, REQ-06

## What

- 入口は `launcher.landing(angle, speed)`。着地の点の x を float で返す。`angle`・`speed` の範囲と `ValueError` は `simulate` と同じ
- 着地の歩は、打ち出しの位置（z ＝ 0.02）を 0 歩目として、i−1 歩目の z が 0.02 より大きく、i 歩目の z が 0.02 以下になる最初の i。返す x は、i−1 歩目と i 歩目の状態を z について線形に補間した x
- `angle` が 15 以上 75 以下で `speed` が 1 以上 8 以下のとき、R ＝ v²·sin(2θ)/9.81 との差が 0.01·R ＋ v·cos(θ)·0.002 以内
- `speed`·sin(`angle`) が 4 以下のとき、`simulate` のすべての歩で z は 0 以上。着地の歩から 1000 歩後の z は 0.015 以上 0.025 以下
- `landing` が対象とする入力は、着地の歩が `simulate` の 20000 歩以内に現れる範囲である。それ以外の入力での扱いは決めない

## 合格条件

- 変えるファイル：`launcher/` の下と `tests/test_launcher_landing.py`
- 試験は、角度と速さの格子（範囲の端を含む）で解析解との差を確かめ、床の試験は着地の歩を `simulate` の出力から自分で探して 1000 歩後を見る
