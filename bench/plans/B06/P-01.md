# 玉の打ち出しと飛行の記録（simulate と入力の検査）
マイルストーン: bench
タスク: P-01
要件: REQ-01, REQ-02, REQ-04

## What

- 入口は `launcher.simulate(angle, speed, steps)`。返り値は長さ `steps` の列で、各要素は辞書。キーは `pos`（x・y・z の 3 個の float）と `vel`（並進の速度の 3 個の float）
- i 番目（0 始まり）の要素は、打ち出しから i+1 歩進んだ後の状態
- `angle` は 5 以上 85 以下、`speed` は 0.5 以上 10 以下の数で、端の値を含む。`steps` は 1 以上 20000 以下の整数で、端の値を含む。`bool`・文字列・`None`・NaN・無限大・整数でない `steps`（`2.0` のような float も含む）・範囲の外の値は、すべて `ValueError`
- 飛行の間（床に着く前）は、`pos` の y と `vel` の y の絶対値が 1e-9 以下で、`pos` の x は前の歩以上。返す値はすべて有限

## 合格条件

- 変えるファイル：`launcher/` の下と `tests/test_launcher_simulate.py`
- 試験は、長さ・キー・float であること、範囲の端と外、`bool` と float の `steps` の拒否、y が 0 に近いこと、x が単調であることを確かめる。着地の後の挙動は確かめない
