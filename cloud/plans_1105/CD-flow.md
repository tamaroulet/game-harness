## 問い

1. **L6 の手順の通し（案 N の形で）。** 提案役の起動から、直しを書く起動・面の検査・対の走り・採点・比べ・回帰の守り・取り込みの判定・マージまで。手順ごとに、誰が（操縦士・会話の席・総監督・bench のアカウント）、何を打つか、何を使うか（枠・トークン・時間）、何が出て、何を見て次へ進むか。戻せない手順に印を付ける。今のコード（`harness/proposer_launch.py`・`harness/bench_pair.py`・`harness/surface.py`・`harness/bench_chain.py`・`harness/chain_score.py`）で足りない所を、ファイル:行つきで挙げる。
2. **Q1 の答えごとの枝。** (a) 両方コマンド無し と (c) 両方コマンドあり のそれぞれで、L6〜L8 の順番・費用・日数がどう変わるか。
3. **L7（2 周を人の手なしで回す）に要る部品と作る順。** 人の手が今どこに残っているかを数え、どれを外すか・外さないかと、その守り。A の「L7 は再現の後」を入れた順番にする。
4. **L8（確立の条件の確かめと、比べの本番）の設計。** 比べ方・回数・費用・成功と失敗の条件。取っておく組（B01〜B04）の鎖を作る手間と時期。単体の相手 A の走らせ方（E5）を作る時期。
5. **L8 より後。** 実戦（Unity）への移し方と、移る見込みの根拠・移らなかったときの手。役割（操縦士・会話の席・総監督・提案役・実装役・Argon）の変え方と、臨時の席（会話の席）を畳む時期。3 か月の見取り図（月ごとの到達点・費用・人の手）と、途中で止める条件。今決めなくてよいことは、今決めなくてよいと書く。
6. **L6 を始める前に決めておかないと、L7・L8・それより後で困ること。** A の Q1〜Q4 に足すものがあれば、多くて 3 つ。
