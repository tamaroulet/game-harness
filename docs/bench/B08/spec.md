# 課題 B08：ばねの鎖（springchain）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/springchain_judge.py`）の検証コマンドだけを渡す。

## 模型

- 質点：n 個（2 ≤ n ≤ 12）。どれも質量 `mass`（kg）。i 番（0 から数える）の質点は、静止の位置 (0.1·i, 0, 0) から x 軸に沿ってだけ、摩擦なしに並進する（自由度 1。変位 x_i、+x が正）
- 壁：静止の位置 x ＝ −0.1 と x ＝ 0.1·n に、動かない壁がある
- ばね：隣り合う質点のあいだ（n − 1 本）と、0 番の質点と左の壁・n−1 番の質点と右の壁のあいだ（2 本）の、合わせて n ＋ 1 本。どれもばね定数 `stiffness`（N/m）で、自然の長さは静止の位置の距離（0.1 m。変位がすべて 0 のとき、どのばねにも力がかからない）
- 減衰：各ばねに並べて、両端の速度の差に比例する減衰（係数 `damping`、N·s/m）を付ける（壁の側の端の速度は 0）。質点と地面のあいだの減衰は無い
- 接触は無い（MuJoCo の `contact` の flag を無効にする）。重力は運動に効かない。時間の刻み 0.002 s・積分は MuJoCo の既定（Euler）
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

状態：`x`（変位 x_0 … x_{n−1} の n 個の float の list）と `v`（速度 v_0 … v_{n−1} の n 個の float の list）を持つ辞書。

エネルギー：E ＝ Σ_i ½·mass·v_i² ＋ ½·stiffness·(x_0² ＋ Σ_{i=0}^{n−2} (x_{i+1} − x_i)² ＋ x_{n−1}²)。始めのエネルギー E0 は、`x0`・`v0` をこの式に入れた値。

固有振動：ω0 ＝ √(stiffness/mass)。p ＝ 1 … n について、ω_p ＝ 2·ω0·sin(p·π/(2(n＋1)))、形 s_p,i ＝ sin((i＋1)·p·π/(n＋1))（i ＝ 0 … n−1）。

## 要件

- REQ-01：公開の入口。リポジトリの根の `springchain` パッケージは、関数 `simulate(n, mass, stiffness, damping, steps, x0=None, v0=None)` を持つ。始めの変位を `x0`、始めの速度を `v0`（どちらも省くとすべて 0）として、`steps` 歩進め、長さ `steps` の list を返す。i 番目は i＋1 歩目の後の状態
- REQ-02：入力の範囲。`n` は 2 以上 12 以下の整数、`mass` は 0.05 以上 0.5 以下の有限の数、`stiffness` は有限の正の数で `stiffness`/`mass` は 4 以上 25 以下、`damping` は 0 以上 0.2 以下の有限の数、`steps` は 1 以上 20000 以下の整数。`x0`・`v0` は `None` か長さ n の list か tuple で、`x0` の各要素は絶対値 0.03 以下、`v0` の各要素は絶対値 1 以下の有限の数。外れた値・数でない値（`bool` を含む）・整数でない `n`・`steps` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、返り値は、すべての値がビット単位で一致する
- REQ-04：始めの状態。1 歩目の状態で、各 i について |x_i − (x0_i ＋ 0.002·v0_i)| ≤ 0.001・|v_i − v0_i| ≤ 0.05
- REQ-05：静止。`x0`・`v0` がすべて 0 なら、どの歩でも、すべての x_i と v_i の絶対値は 1e-12 以下
- REQ-06：エネルギーの保存。`damping` が 0 なら、5000 歩までのどの歩でも、状態のエネルギー E は E0 の 0.97 倍以上 1.03 倍以下
- REQ-07：減衰。`damping` が 0.1 以上 0.2 以下・`mass` が 0.1 以下・`n` が 6 以下で E0 ＞ 0 なら、5000 歩までのどの歩でも E ≤ 1.03·E0 で、5000 歩目の E は 0.5·E0 以下
- REQ-08：固有振動の周期。`damping` が 0 で、`x0` ＝ A·s_p（0.005 ≤ A ≤ 0.03、1 ≤ p ≤ n）・`v0` がすべて 0 なら、T ＝ 2π/ω_p として、N ＝ round(T/0.002) 歩目の各 x_i と A·s_p,i の差、H ＝ round(T/0.004) 歩目の各 x_i と −A·s_p,i の差は、どれも 0.02·A 以内
- REQ-09：ばねの間の減衰。`damping` が 0.02 以下・`mass` が 0.1 以上・`stiffness`/`mass` が 16 以上で、`x0` ＝ A·s_p・`v0` がすべて 0 なら、1000 歩目の E ÷ E0 は、exp(−(damping/mass)·(ω_p/ω0)²·2) の 0.9 倍以上 1.1 倍以下（減衰は、その固有振動の振動数の 2 乗に比例して効く）
- REQ-10：相似。`mass`・`stiffness`・`damping` をすべて 2 倍にした（範囲の内）`simulate` の各歩の x_i と v_i は、元との差が 1e-9 以内
- REQ-11：線形と鏡。`x0`・`v0` をすべて 2 倍にした（範囲の内）`simulate` の各歩の x_i と v_i は、元の 2 倍との差が 1e-9 以内。`x0`・`v0` を並びの逆順にして符号を反転した `simulate` の各歩で、x_i と v_i は、元の x_{n−1−i} と v_{n−1−i} の符号を反転したものとの差が 1e-9 以内
