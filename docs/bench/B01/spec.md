# 課題 B01：玉転がし（rollgame）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/rollgame_judge.py`）の検証コマンドだけを渡す。

## 模型

- 盤：上面が高さ 0 の水平な箱。上面の範囲は x・y とも -0.5 以上 0.5 以下（m）、厚さ 0.02 m（中心 (0, 0, -0.01)）。盤は動かない。縁に壁は無く、盤の下に床も無い
- 玉：半径 0.02 m・質量 0.05 kg の球 1 個。自由に動ける（並進 3・回転 3）。初めは中心 (-0.35, -0.35, 0.02)（盤に接した位置）で静止
- 傾き：入力 (tx, ty)（rad）。盤は動かさず、その歩の重力の向きで表す：重力 ＝ 9.81 × (sin tx, sin ty, −cos tx · cos ty)（m/s²）
- ゴール：盤の上の中心 (0.35, 0.35)・半径 0.05 m の円
- 接触・摩擦・積分は MuJoCo の既定値（摩擦 (1, 0.005, 0.0001)、condim 3、`solref` (0.02, 1)、Euler）。空気抵抗なし。時間の刻み 0.002 s
- 1 回の遊びの上限は 5000 歩。物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

## 要件

- REQ-01：公開の入口。リポジトリの根の `rollgame` パッケージは `Game` を持つ。`Game()` は模型の初めの状態の遊びを作る。`step(tx, ty)` は傾き (tx, ty) で 1 歩進め、辞書を返す。辞書は `pos`（玉の中心の x・y・z の 3 個の float の list）・`vel`（並進の速度の 3 個の float の list）・`outcome`（`None`・`"goal"`・`"fell"`・`"timeout"` のどれか）を持つ
- REQ-02：入力の範囲。`tx`・`ty` は -0.2 以上 0.2 以下の有限の数。範囲の外の値・数でない値（`bool` を含む）には `ValueError` を投げる（遊びが終わった後も同じ）
- REQ-03：決定論。2 つの `Game` を同じ入力の列で進めると、返る辞書は、すべての値がビット単位で一致する
- REQ-04：静止。傾き (0, 0) で 1000 歩進めると、玉の中心の x・y は初めの位置から 0.001 m 以内にあり、`outcome` はずっと `None`
- REQ-05：転がり。傾き (0, 0) で 100 歩進めた後、傾き (t, 0)（0.05 ≤ |t| ≤ 0.2）を n 歩（100 ≤ n ≤ 180）続けたとき、その n 歩での x の変化 Δx は t と同じ符号で、|Δx| は ½ · 9.81 · |sin t| · (0.002·n)² の 0.64 倍以上 0.80 倍以下（滑らずに転がる球の 5/7 を含む帯）。y の変化は 0.001 m 未満。傾き (0, t) でも、x と y を入れ替えて同じ
- REQ-06：対称。入力の列の各歩の (tx, ty) を (ty, tx) に替えた遊びでは、各歩の `pos` と `vel` の x と y が入れ替わる（差は 1e-4 以内）。`outcome` の列は同じ
- REQ-07：盤の上。玉の中心の x・y がともに -0.45 以上 0.45 以下の歩では、中心の高さ z は 0.015 以上 0.025 以下
- REQ-08：落ちる。中心の高さ z が -0.05 未満になった最初の歩で `outcome` は `"fell"` になる。傾き (t, s)（-0.2 ≤ t ≤ -0.1、|s| ≤ 0.05）を続けると、5000 歩以内に `"fell"` になる
- REQ-09：ゴール。中心の高さ z が 0 以上で、x・y がゴールの円の中（境界を含む）にある最初の歩で `outcome` は `"goal"` になる。傾き (t, t)（0.06 ≤ t ≤ 0.15）を続けると、5000 歩以内に `"goal"` になる
- REQ-10：時間切れ。ほかの終わりが無いまま 5000 歩目を進めた歩で `outcome` は `"timeout"` になる。同じ歩で REQ-08・REQ-09 の条件も満たすときは、`"fell"`・`"goal"`・`"timeout"` の順に先のものになる
- REQ-11：終わった後。`outcome` が `None` でなくなった後の `step` は、玉の状態を変えず、終わった歩と同じ `pos`・`vel`・`outcome` を返す
