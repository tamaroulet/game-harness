# 課題 B10：迷路の玉（maze）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/maze_judge.py`）の検証コマンドだけを渡す。

## 模型

- 格子：文字列の list（R 行 × C 列）。文字は `#`（壁）・`.`（床）・`S`（始め）・`G`（ゴール）の 4 つ
- 座標：r 行 c 列（どちらも 0 から数える）のセルの中心は (0.1·c ＋ 0.05, 0.1·(R − 1 − r) ＋ 0.05)。セルは 1 辺 0.1 m の正方形で、x は c とともに、y は r とともに減る向きに並ぶ。鉛直の上向きを +z とする
- 盤：高さ 0 の無限の平面が床。`#` のセルごとに、大きさ 0.1 × 0.1 × 0.1 m（半分の大きさ (0.05, 0.05, 0.05)）の動かない直方体を、中心 (セルの中心の x, y, 0.05) に置く
- 玉：半径 0.03 m・質量 0.1 kg の中実の球。自由に動ける（並進 3・回転 3）。始めは `S` のセルの中心の高さ 0.03 に静止で置く
- 傾き：歩ごとの入力 (a_x, a_y)（どちらも絶対値 0.1 以下）。その歩の重力の加速度を 9.81·(a_x, a_y, −√(1 − a_x² − a_y²)) にする（盤を傾ける代わりに重力を傾ける）
- 接触：床・壁・玉のすべての geom に、摩擦 (1, 0.005, 0.0001) と `solref` (0.004, 1) を付ける。ほかの接触・積分は MuJoCo の既定（condim 3・pyramidal の錐・Euler）。時間の刻み 0.002 s
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

状態：玉の中心の `x`・`y`・`z`（m、float）を持つ辞書。玉の中心が、あるセルの中心から x・y の両方で 0.05 未満のとき、玉はそのセルの中にあるとする。

## 要件

- REQ-01：公開の入口。リポジトリの根の `maze` パッケージは、次の 2 つの関数を持つ。
  - `simulate(grid, tilts)` は、始めの状態から、`tilts` の k 番目の傾きで k＋1 歩目を進め、長さ `len(tilts)` の list を返す。k 番目は k＋1 歩目の後の状態
  - `solve(grid)` は、`S` から `G` へ玉を運ぶ傾きの list（各要素は 2 つの float の tuple）を返す。運べない格子では `None` を返す
- REQ-02：入力の範囲。`grid` は 5 行以上 9 行以下の文字列の list で、どの行も同じ長さ（5 以上 9 以下）、文字は 4 つのどれか、`S` と `G` はちょうど 1 つずつ、一番外の行と列はすべて `#`。`tilts` は 1 個以上 20000 個以下の list で、各要素は 2 つの有限の数（`bool` を除く）の list か tuple、どちらも絶対値 0.1 以下。外れた値には `ValueError` を投げる（`solve` も同じ `grid` の検査をする）
- REQ-03：決定論。同じ引数で 2 回呼ぶと、返り値は、すべての値がビット単位で一致する
- REQ-04：静止。`tilts` がすべて (0, 0) なら、どの歩でも、玉の中心の x・y は始めの位置から 1e-6 以内
- REQ-05：転がり。玉が `S` から 0.3 m 以内の壁に触れない盤（`S` のまわりの 7 × 7 のセルに `#` が無い）で、`tilts` がすべて同じ (a_x, a_y) なら、400 歩までの各 k 歩目（t ＝ 0.002·k）で、x − x_S と ½·(5/7)·9.81·a_x·t² の差、y − y_S と ½·(5/7)·9.81·a_y·t² の差は、どちらも 0.03·|その値| ＋ 0.002 以内（玉は滑らずに転がり、加速度は傾きの 5/7）
- REQ-06：壁。どんな `tilts` でも、どの歩でも、玉は `#` のセルの中に無く、0 ＜ z ＜ 0.1
- REQ-07：解ける格子。`S` と `G` が、`#` でないセルを上下左右に辿ってつながっているなら、`solve(grid)` は長さ 20000 以下の list を返し、`simulate(grid, solve(grid))` の状態のどれかで、玉は `G` のセルの中にある
- REQ-08：解けない格子。つながっていないなら、`solve(grid)` は `None`
- REQ-09：鏡。各行の文字の並びを逆にした格子と、a_x の符号を反転した `tilts` の `simulate` の各歩で、x は元の 0.1·C − x と 1e-6 以内、y と z は元と 1e-6 以内で一致する（REQ-05 の盤で、400 歩まで）
