# 課題 B04：ドミノ（domino）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/domino_judge.py`）の検証コマンドだけを渡す。

## 模型

- 床：高さ 0 の無限の平面
- 板：大きさ 0.01 × 0.05 × 0.1 m（厚さ・幅・高さ。半分の大きさ (0.005, 0.025, 0.05)）・質量 0.03 kg の直方体を n 枚（2 ≤ n ≤ 12）。どれも自由に動ける（並進 3・回転 3）
- 並べ方：入力は、枚数 `n`・間隔 `spacing`（隣り合う板の中心の距離、m）・始めの点 `origin`（x・y）・進む向き `direction`（`"+x"`・`"-x"`・`"+y"`・`"-y"` のどれか。その向きの水平の単位ベクトルを e とする）。i 番（0 から数える）の板は、中心を origin ＋ i·`spacing`·e・高さ 0.05 に、厚さの向きを e にそろえて鉛直に立て、静止で置く
- 押し出し：0 番の板だけは、鉛直に立てたときの進む向きの側の下の辺（中心から e の向きに 0.005 m・高さ 0 の辺）を軸にして、上の端が e の向きへ行くように 0.2 rad 傾けて、静止で置く（この辺が床に接する）
- 接触の `solref` は (0.004, 1)（床と各板の geom に付ける）。ほかの接触・摩擦・積分は MuJoCo の既定値（摩擦 (1, 0.005, 0.0001)、condim 3、Euler）。重力は −z 向きに 9.81 m/s²。時間の刻み 0.002 s
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

板の状態：`pos`（中心の x・y・z の 3 個の float の list）と `tilt`（板の高さの向きの軸と、鉛直の上向き +z のなす角。rad、0 以上 π 以下の float）を持つ辞書。`tilt` が 1.2 を超えた板を、倒れたとする。

## 要件

- REQ-01：公開の入口。リポジトリの根の `domino` パッケージは、次の 2 つの関数を持つ。
  - `simulate(n, spacing, steps, origin=(0.0, 0.0), direction="+x")` は、置いた状態から `steps` 歩進め、長さ `steps` の list を返す。i 番目は i+1 歩目の後の状態で、長さ n の list（0 番の板から順に、板の状態）
  - `fall_steps(n, spacing, steps=3000, origin=(0.0, 0.0), direction="+x")` は、置いた状態から `steps` 歩進め、長さ n の list を返す。i 番目は、i 番の板の `tilt` が 1.2 を超えた最初の歩の番号（1 歩目を 1 と数える整数）で、`steps` 歩までに超えなければ `None`
- REQ-02：入力の範囲。`n` は 2 以上 12 以下の整数、`spacing` は 0.04 以上 0.2 以下の有限の数、`steps` は 1 以上 20000 以下の整数、`origin` は長さ 2 の list か tuple で、各要素は絶対値 1 以下の有限の数、`direction` は 4 つの文字列のどれか。外れた値・数でない値（`bool` を含む）・整数でない `n`・`steps`・4 つのどれでもない `direction` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、2 つの関数の返り値は、すべての値がビット単位で一致する
- REQ-04：置いた位置。`simulate` の 1 歩目の状態で、1 番から後の板の中心は置いた位置から 0.001 m 以内で、`tilt` は 0.01 以下。0 番の板の中心は置いた位置から 0.002 m 以内で、`tilt` と 0.2 の差は 0.01 以内
- REQ-05：届かない。`spacing` が 0.125 以上なら、3000 歩のどの歩でも、1 番から後の板の中心は置いた位置から 0.002 m 以内で、`tilt` は 0.02 以下。`fall_steps(n, spacing, 3000, origin, direction)` は、0 番が 1000 以下の整数で、ほかはすべて `None`。3000 歩目の 0 番の板の中心は、高さが 0.01 以下で、origin から e の向きに 0.04 以上 0.07 以下、e に垂直な向きに 0.01 以内にある（進む向きへ倒れて床に伏す）
- REQ-06：倒れ続ける。`spacing` が 0.05 以上 0.065 以下で、`n` が 3 以上 10 以下なら、`fall_steps(n, spacing, 3000, origin, direction)` の要素はすべて整数で、0 番から順に減らない（i 番の値 ≤ i+1 番の値）。3000 歩目の状態で、どの板の `tilt` も 1.2 より大きい
- REQ-07：床。どの歩でも、各板の中心の高さは 0 以上
- REQ-08：平行移動と回転。`n`・`spacing` が REQ-06 の範囲のとき、`origin` を範囲の中で変えても、`direction` を 4 つのどれに替えても、`fall_steps(n, spacing, 3000, origin, direction)` の各要素は、`origin` ＝ (0, 0)・`direction` ＝ `"+x"` のときの値との差が 10 歩以内
