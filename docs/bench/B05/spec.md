# 課題 B05：積み木の塔（tower）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/tower_judge.py`）の検証コマンドだけを渡す。

## 模型

- 床：高さ 0 の無限の平面
- 箱：大きさ 0.1 × 0.1 × 0.05 m（x・y・z。半分の大きさ (0.05, 0.05, 0.025)）・質量 0.1 kg の直方体を k 個（1 ≤ k ≤ 6）。どれも自由に動ける（並進 3・回転 3）
- 積み方：入力 `offsets`（長さ k の数の列）。下から j 番目（0 から数える）の箱の中心を (offsets[j], 0, 0.025 + 0.05·j) に、向きをそろえて（回転なし）静止で置く。隣り合う箱は面で接する
- 接触の `solref` は (0.004, 1)（床と各箱の geom に付ける）。ほかの接触・摩擦・積分は MuJoCo の既定値（摩擦 (1, 0.005, 0.0001)、condim 3、Euler）。重力は -z 向きに 9.81 m/s²。時間の刻み 0.002 s
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

支えの余裕：j ＝ 0 … k−2 について、箱 j より上の箱（j+1 … k−1）の中心の x の平均を c_j とし、d_j ＝ |c_j − offsets[j]| とする（箱の質量は等しいので、c_j は上の箱の重心の x）。

## 要件

- REQ-01：公開の入口。リポジトリの根の `tower` パッケージは、次の 3 つの関数を持つ。`simulate(offsets, steps)` は置いた状態から `steps` 歩進め、長さ `steps` の list を返す。i 番目は i+1 歩目の後の状態で、長さ k の list（下の箱から順）。その各要素は `pos`（箱の中心の x・y・z の 3 個の float の list）と `vel`（並進の速度の 3 個の float の list）を持つ辞書。`stands(offsets)` は塔が立つか（`bool`）を返す。`harmonic(k)` は REQ-07 の積み方の `offsets`（k 個の float の list）を返す
- REQ-02：入力の範囲。`offsets` は長さ 1 以上 6 以下の list か tuple で、各要素は絶対値 0.5 以下の有限の数、隣り合う要素の差の絶対値は 0.1 以下。`steps` は 1 以上 20000 以下の整数。`k` は 1 以上 6 以下の整数。外れた値・数でない値（`bool` を含む）・整数でない `steps`・`k` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、3 つの関数の返り値は、すべての値がビット単位で一致する
- REQ-04：置いた位置。`simulate` の 1 歩目の状態で、各箱の中心は置いた位置から 0.001 m 以内にある
- REQ-05：立つ。すべての j で d_j ≤ 0.04 なら、`stands` は `True` で、`simulate(offsets, 2000)` のどの歩でも、各箱の中心は置いた位置から 0.005 m 以内にある
- REQ-06：崩れる。ある j で d_j ≥ 0.06 なら、`stands` は `False`
- REQ-07：調和の積み方。`harmonic(k)` は、offsets[0] ＝ 0 で、j ＝ 0 … k−2 について offsets[j+1] − offsets[j] ＝ 0.8 × 0.05 / (k − 1 − j) の列を返す（差は 1e-12 以内）。k ＝ 1 … 6 のどれでも `stands(harmonic(k))` は `True` で、k ≥ 4 では一番上の箱の中心が一番下の箱の縁より外にある（offsets[k−1] − offsets[0] ＞ 0.05）
- REQ-08：鏡と平行移動。REQ-05 の立つ積み方では、`offsets` の符号をすべて反転した積み方の `simulate` の各歩の各箱の `pos` の x は符号が反転し（差は 1e-3 以内）、`offsets` のすべてに同じ数 c を足した積み方（範囲の内）の x は c だけずれる（差は 1e-3 以内）。どちらの積み方でも、`stands` の値は元の積み方と同じ。REQ-06 の崩れる積み方でも、`stands` の値は同じ
- REQ-09：床。`simulate` のどの歩でも、各箱の中心の高さ z は 0.015 以上
- REQ-10：立つの定義。`stands(offsets)` は、`simulate(offsets, 2000)` の最後の歩で、一番上の箱の中心の高さ z が、置いた高さ 0.025 + 0.05·(k−1) の 0.95 倍以上のとき、かつそのときだけ `True`
