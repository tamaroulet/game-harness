# 練習の課題 P1：単振り子（pendulum）

計画役と監修のループの確定の率を測るための練習の課題（D-106 §7.3）。ベンチの 10 本には入らず、採点もしない。

## 模型

- 振り子：長さ `length`（m）の重さの無い棒の先に、質量 0.2 kg・半径 0.02 m の中実の球。棒の根は原点に固定した y 軸まわりの蝶番の関節で、球は x–z の面の中だけで動く。角 θ は鉛直の下向きから測り、+x の側へ振れる向きを正とする
- 重力は −z 向きに 9.81 m/s²。関節の減衰は `damping`（N·m·s/rad）。接触は無い。時間の刻み 0.002 s・積分は MuJoCo の既定（Euler）
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

状態：`theta`（rad）と `omega`（rad/s）を持つ辞書。

## 要件

- REQ-01：公開の入口。リポジトリの根の `pendulum` パッケージは、関数 `simulate(length, damping, theta0, steps)` と `period(length, theta0)` を持つ。`simulate` は、角 `theta0`・角速度 0 から `steps` 歩進め、長さ `steps` の状態の list を返す。`period` は、減衰 0 のときの周期（s）を、`simulate` の角が正から負へ 0 を 2 回目に横切るまでの時間から求めて返す
- REQ-02：入力の範囲。`length` は 0.1 以上 2 以下、`damping` は 0 以上 0.05 以下、`theta0` は −1.5 以上 1.5 以下の有限の数、`steps` は 1 以上 20000 以下の整数。外れた値・数でない値（`bool` を含む）・整数でない `steps` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、返り値は、すべての値がビット単位で一致する
- REQ-04：小さな振れの周期。|`theta0`| ≤ 0.05 なら、`period` は 2π·√(I/(m·g·d)) と 0.5% 以内で一致する（I は根のまわりの慣性のモーメント、d は根から重心までの長さ）
- REQ-05：大きな振れは遅い。`period(length, a)` は、0 ＜ a ＜ b ≤ 1.5 なら `period(length, b)` より小さい
- REQ-06：エネルギー。`damping` が 0 なら、5000 歩までのどの歩でも、力学的なエネルギーは始めの値の 0.98 倍以上 1.02 倍以下。`damping` が 0 より大きければ、5000 歩目のエネルギーは始めの値より小さい
- REQ-07：鏡。`simulate(length, damping, −theta0, steps)` の各歩の `theta` と `omega` は、元の符号を反転したものと 1e-9 以内で一致する
