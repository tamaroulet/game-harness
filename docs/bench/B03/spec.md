# 課題 B03：ビリヤード（billiards）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/billiards_judge.py`）の検証コマンドだけを渡す。

## 模型

- 台：x が −0.5 以上 0.5 以下、y が −0.25 以上 0.25 以下（m）の長方形。四辺に縁（クッション）がある。縁は動かない直方体で、内側の面が x ＝ ±0.5・y ＝ ±0.25 の平面にある（四隅も縁でふさがっている）
- 球：半径 0.025 m・質量 0.16 kg の球 2 個（手球 `cue` と的球 `target`）。どちらも水平の面の中だけを動く。x 向きと y 向きのスライドの関節を 1 つずつ持ち（自由度 2）、回らず、高さは変わらない
- 抵抗：各球の 2 つのスライドの関節に damping 0.24（N·s/m）を付ける（台の上の抵抗を、速度に比例する力 −0.24·v で表す）
- 接触：球と球、球と縁だけ（球と台の面の接触は無い）。摩擦なし（`condim` 1）・`solref` (0.1, 0.05)（よく弾む）・`solimp` は MuJoCo の既定。重力は −z 向きに 9.81 m/s²（球は水平にしか動かないので、運動には効かない）。時間の刻み 0.002 s・積分は MuJoCo の既定（Euler）
- ポケット：台の四隅 (±0.5, ±0.25) を中心とする半径 0.05 m の円。球の中心がこの円の中（境界を含む）に入った最初の歩で、その球はポケットに入ったとする。ポケットに入った球は台から除かれ、以後はどの球とも縁とも接触せず、状態は変わらない
- 打ち出し：始めは、手球の中心が `cue`、的球の中心が `target` の位置にあり、どちらも静止。手球に、速さ `speed`（m/s）・向き `angle`（度。+x 向きが 0、+y 向きが 90）の速度を与えてから、1 歩目を進める
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

球の状態：`pos`（中心の x・y の 2 個の float の list）・`vel`（速度の x・y の 2 個の float の list）・`pocketed`（`bool`）を持つ辞書。ポケットに入った球は、入った歩の `pos` を保ち、`vel` は `[0.0, 0.0]`、`pocketed` は `True`。球の速さは `vel` の大きさ。

## 要件

- REQ-01：公開の入口。リポジトリの根の `billiards` パッケージは、次の 2 つの関数を持つ。
  - `simulate(cue, target, speed, angle, steps)` は、打ち出しから `steps` 歩進め、長さ `steps` の list を返す。i 番目は i+1 歩目の後の状態で、辞書 `{"cue": 手球の状態, "target": 的球の状態}`
  - `shot(cue, target, speed, angle)` は、打ち出しから、ポケットに入っていない球の速さがすべて 0.001 m/s 未満になる最初の歩まで進める（20000 歩で打ち切る）。辞書 `{"steps": 進めた歩数（整数）, "cue": 最後の手球の状態, "target": 最後の的球の状態}` を返す
- REQ-02：入力の範囲。`cue`・`target` は長さ 2 の list か tuple で、x は絶対値 0.45 以下、y は絶対値 0.2 以下の有限の数。2 つの中心の距離は 0.06 以上。`speed` は 0.1 以上 2.0 以下の有限の数、`angle` は有限の数、`steps` は 1 以上 20000 以下の整数。外れた値・数でない値（`bool` を含む）・整数でない `steps` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、2 つの関数の返り値は、すべての値がビット単位で一致する
- REQ-04：始めの状態。`simulate` の 1 歩目の状態で、手球の `pos` は `cue` から 0.005 m 以内、`vel` と打ち出しの速度 (speed·cos angle, speed·sin angle) の差の大きさは 0.01·speed 以内。的球の `pos` は `target` から 1e-6 m 以内で、速さは 1e-6 以下。どちらの `pocketed` も `False`
- REQ-05：減速。縁にも的球にも触れずに止まる打ち出しでは、`shot` の最後の手球の `pos` と `cue` の距離は、speed ÷ 1.5 の 0.99 倍以上 1.01 倍以下で、`cue` から見たその向きと `angle` の差は 0.001 rad 以内
- REQ-06：止まる。`shot` の `steps` は 3000 以下で、最後の状態でポケットに入っていない球の速さは、どれも 0.001 未満
- REQ-07：正面衝突。2 つの中心の y が等しく、的球が手球の +x の側にあり、`angle` が 0 の打ち出しで、2 つの中心の距離が 0.05 以下になった最初の歩を接触の始め、その後で 0.05 を超えた最初の歩を接触の終わりとする。接触の終わりの手球の速さは、接触の始めの手球の速さの 0.2 倍以下、的球の速さは 0.75 倍以上 1.0 倍以下で、的球の速度の y の絶対値は 1e-6 以下
- REQ-08：縁。ポケットに入っていない球の中心は、どの歩でも |x| ≤ 0.49・|y| ≤ 0.24 にある。`angle` が 0 で、ほかの球に触れずに +x の縁に当たる手球について、中心の x が 0.47 以上になった最初の歩の 1 つ前の歩の速度の x を v1、その後で x が 0.47 未満に戻った最初の歩の速度の x を v2 とすると、−v2 ÷ v1 は 0.6 以上 1.0 以下。そのあいだのどの歩でも、中心の y と `cue` の y の差は 1e-6 以内
- REQ-09：ポケット。球の中心が四隅のどれかから 0.05 以内に入った最初の歩で、その球の `pocketed` は `True` になり、以後の歩で `pos` は変わらず `vel` は `[0.0, 0.0]`。隅の 1 つを C とし、C から台の内側へ、x 軸と 35° 以上 55° 以下の角をなす直線を引く。その直線の上で C から距離 L（0.2 ≤ L ≤ 0.35）の点に手球を置き、C の向きに 0.8 ≤ speed ≤ 1.5 で打つと（的球はその直線から 0.1 m 以上離れた位置）、手球はポケットに入る。同じ直線の上で、C から距離 L（0.15 ≤ L ≤ 0.25）の点に的球を、その 0.1 m 後ろに手球を置き、C の向きに 1.0 ≤ speed ≤ 1.5 で打つと、的球はポケットに入る
- REQ-10：鏡。`cue`・`target` の y の符号を反転し、`angle` を −`angle` にした打ち出しの各歩の状態は、元の打ち出しの状態の `pos` と `vel` の y の符号を反転したものに等しい（差は 1e-6 以内）。`cue`・`target` の x の符号を反転し、`angle` を 180 − `angle` にしたときは、x について同じ。どちらでも `pocketed` は元と同じ
