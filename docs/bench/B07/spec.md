# 課題 B07：坂を登る車（hillcar）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/hillcar_judge.py`）の検証コマンドだけを渡す。

## 模型

- 座標：坂の面を z ＝ 0 の平面（無限）とし、坂を登る向きを +x、面の法線の上向きを +z とする。坂の角 α（度）は、重力を傾けて表す：重力の加速度は (−9.81·sin α, 0, −9.81·cos α)。α ＞ 0 なら +x が登り
- 車体：大きさ 0.1 × 0.06 × 0.04 m（x・y・z。半分の大きさ (0.05, 0.03, 0.02)）・質量 1.0 kg の直方体。中心は始めに (0, 0, 0.1)。車体の関節は、x 向きのスライド・z 向きのスライド・y 軸まわりの蝶番の 3 つ（この順。どれも車体の中心にあり、車体は x–z の面の中だけで動く）
- 輪：半径 0.1 m・質量 0.25 kg の中実の球を 2 つ。後輪の中心は車体の中心から (−0.05, 0.12, 0)、前輪の中心は (+0.05, −0.12, 0)（y をずらして、2 つの輪が重ならないようにする）。それぞれ車体に対して y 軸まわりの蝶番の関節で回る（関節の減衰・摩擦・armature は 0）。始めは、両輪が面にちょうど接する
- 駆動：後輪の蝶番の関節だけに、トルク `torque`（N·m）を始めから終わりまで一定にかける（MuJoCo の `motor`、gear 1。反作用は車体にかかる）。前輪は自由に回る。正のトルクは車を +x 向きに進める向き
- 接触：面・車体・輪のすべての geom に、摩擦 (1, 0.005, 0.0001) と `solref` (0.004, 1) を付ける。ほかの接触・積分は MuJoCo の既定（condim 3・pyramidal の錐・Euler）。時間の刻み 0.002 s
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

状態：次の 4 つを持つ辞書。
- `x`：車体の中心の x（m、float）
- `z`：車体の中心の z（m、float）
- `pitch`：車体の傾き（rad、−π より大きく π 以下の float）。前（+x の側）が持ち上がる向きを正とする
- `flipped`：車体の上向きの軸（始めの +z）と面の法線 +z の内積が 0 未満になった歩があれば、その歩から後はずっと `True`、それまでは `False`（bool）

記号：M ＝ 1.5 kg（車体と両輪）、有効の質量 M_e ＝ M ＋ 2·(2/5·0.25·0.1²)/0.1² ＝ 1.7 kg、浮き上がりのトルク τ*(α) ＝ 0.05·M·9.81·cos α。車体と両輪を合わせた重心は車軸の高さにあり、輪が滑らずに車体が傾かない間、前輪の法線の力は ½·(M·9.81·cos α − `torque`／0.05) になる（`torque` ＞ τ*(α) で前が浮く）。

## 要件

- REQ-01：公開の入口。リポジトリの根の `hillcar` パッケージは、関数 `simulate(slope, torque, steps)` を持つ。坂の角 `slope`（度）とトルク `torque` で、始めの状態から `steps` 歩進め、長さ `steps` の list を返す。i 番目は i＋1 歩目の後の状態
- REQ-02：入力の範囲。`slope` は −40 以上 40 以下の有限の数、`torque` は −1.2 以上 1.2 以下の有限の数、`steps` は 1 以上 20000 以下の整数。外れた値・数でない値（`bool` を含む）・整数でない `steps` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、返り値は、すべての値がビット単位で一致する
- REQ-04：始めの状態。1 歩目の状態で、|x| ≤ 0.001・|z − 0.1| ≤ 0.001・|pitch| ≤ 0.01・`flipped` は `False`
- REQ-05：静止。`slope` が 0 で `torque` が 0 なら、どの歩でも |x| ≤ 1e-6・|pitch| ≤ 1e-6・`flipped` は `False`
- REQ-06：転がり。−20 ≤ `slope` ≤ 40 かつ −0.1 ≤ `torque` ≤ 0.8·τ*(α) なら、a ＝ (`torque`／0.1 − M·9.81·sin α)／M_e として、1000 歩までの各 k 歩目（t ＝ 0.002·k）で |x − ½·a·t²| ≤ 0.03·|½·a·t²| ＋ 0.1・|pitch| ≤ 0.02・`flipped` は `False`（輪は滑らずに転がり、坂の分の重力と輪の回りにくさが効き、前は浮かない）。とくに、30° 以上の坂では、前が浮かずにかけられるトルクでは登れず、下がる（tan α ＞ 0.5）
- REQ-07：ひっくり返る。|`slope`| ≤ 20 かつ 1.5·τ*(α) ≤ |`torque`| ≤ 1.2 なら、600 歩目の `flipped` は `True`。|pitch| が初めて 0.5 を超えた歩の `pitch` は、`torque` と同じ符号（正のトルクでは前が持ち上がり、負のトルクでは後ろが持ち上がる）
- REQ-08：鏡。|`slope`| ≤ 10 かつ |`torque`| ≤ 0.1 なら、`simulate(−slope, −torque, steps)` の各歩（500 歩まで）で、x は元の −x との差が 0.01·|x| ＋ 0.02 以内、pitch は元の −pitch との差が 0.001 以内、z は元との差が 0.0001 以内（重心が車軸の高さにあるので、転がる間は、どちらの輪で駆動しても進み方と法線の力の分かれ方が同じ）
