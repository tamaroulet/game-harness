# 課題 B02：倒立振子（cartpole）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/cartpole_judge.py`）の検証コマンドだけを渡す。

## 模型

- 台車：質量 1.0 kg。x 軸に沿ったレールの上を、摩擦なしに並進する（自由度 1。位置 x、向きは +x）。レールの端の止めは無い
- 棒：長さ 0.5 m・質量 0.1 kg の一様な棒（`capsule`、半径 0.01 m、台車の中心から +z 向きに 0 〜 0.5 m）。台車の中心を通る y 軸まわりの蝶番で台車につながる（自由度 1。角度 θ は鉛直の上向きからの傾きで、棒の先が +x の側に傾くとき正）
- 入力：台車に x 向きにかける力 f（N）。1 歩ごとに 1 つの値。|f| ≤ 10
- 接触は無い（MuJoCo の `contact` の flag を無効にする）。関節の減衰・摩擦・armature は 0。重力は -z 向きに 9.81 m/s²。時間の刻み 0.002 s・積分は MuJoCo の既定（Euler）
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する

状態：4 つの float `x`（m）・`x_dot`（m/s）・`theta`（rad）・`theta_dot`（rad/s）を持つ辞書。

始めの状態：台車は x ＝ x0、棒は θ ＝ θ0、速度はどちらも 0。

## 要件

- REQ-01：公開の入口。リポジトリの根の `cartpole` パッケージは、次の 3 つの関数を持つ。
  - `simulate(theta0, forces, x0=0.0)` は、始めの状態から、i 歩目に力 `forces[i]` をかけて `len(forces)` 歩進め、長さ `len(forces)` の list を返す。i 番目は i+1 歩目の後の状態
  - `episode(theta0, policy, max_steps=5000, x0=0.0)` は、始めの状態から、各歩の前にその時の状態（辞書）を `policy` に渡して力を受け取り、その力で 1 歩進める。REQ-09 の順で終わりを判定し、辞書 `{"status": 終わり方の文字列, "steps": 進めた歩数, "state": 最後の状態}` を返す
  - `balance(state)` は、状態から力（`float`）を返す制御器。REQ-11 を満たす
- REQ-02：入力の範囲。`theta0` は絶対値 0.4 以下の有限の数、`x0` は絶対値 0.95 以下の有限の数。`forces` は長さ 1 以上 20000 以下の list か tuple で、各要素は絶対値 10 以下の有限の数。`max_steps` は 1 以上 20000 以下の整数。`policy` は呼び出せるもの。`balance` の `state` は REQ-01 の 4 つの鍵を持ち、値がどれも有限の数の辞書。外れた値・数でない値（`bool` を含む）・整数でない `max_steps`・呼び出せない `policy` には `ValueError` を投げる。`episode` の中で `policy` が絶対値 10 以下の有限の数でない値を返したときも `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、`simulate` の返り値と、`policy` に `balance` を渡した `episode` の返り値は、すべての値がビット単位で一致する
- REQ-04：始めの状態。`simulate(theta0, [0.0], x0)` の状態で、|x − x0| ≤ 1e-4、|θ − θ0| ≤ 1e-3、|x_dot| ≤ 0.1、|θ_dot| ≤ 0.1
- REQ-05：力への応答。θ0 ＝ 0・x0 ＝ 0 から、絶対値 3 以上 8 以下の一定の力 f を 25 歩かけた後、`x_dot` ÷ (f × 0.05) は 0.96 以上 0.99 以下、`theta_dot` ÷ (f × 0.05) は −3.1 以上 −2.8 以下
- REQ-06：重心。力が常に 0 のとき、系の重心の x、(1.0·x ＋ 0.1·(x ＋ 0.25·sin θ)) ÷ 1.1 は、どの歩でも始めの値から 0.002 m 以内にある
- REQ-07：倒れる。力が常に 0 の `policy` で、0.005 ≤ |θ0| ≤ 0.02・x0 ＝ 0 から始めた `episode` は、`status` が `"fallen"` で、`steps` は 250 以上 1500 以下、最後の状態の θ は θ0 と同じ符号
- REQ-08：はみ出す。0.9 ≤ |x0| ≤ 0.95・θ0 ＝ 0 から、x0 と同じ符号の向きに大きさ 10 の一定の力をかける `policy` の `episode` は、`status` が `"out"` で、`steps` は 100 以下、最後の状態で |x| ＞ 1
- REQ-09：終わり方の順。`episode` は、1 歩進めるごとに、|θ| ＞ 0.5 なら `"fallen"`、そうでなく |x| ＞ 1 なら `"out"`、そうでなく進めた歩数が `max_steps` なら `"timeout"` で終わる。どれでもなければ次の歩に進む。力が常に 0 の `policy` で、0.005 ≤ |θ0| ≤ 0.02 から、20 以上 200 以下の `max_steps` で始めた `episode` は、`status` が `"timeout"` で、`steps` は `max_steps`
- REQ-10：鏡。`simulate(−theta0, [−f for f in forces], −x0)` の各歩の状態の 4 つの値は、`simulate(theta0, forces, x0)` の同じ歩の値の符号を反転したものに等しい（差は 1e-6 以内）
- REQ-11：立て直す。|θ0| ≤ 0.1・|x0| ≤ 0.3 のどの始めの状態からも、`episode(theta0, balance, 5000, x0)` は `status` が `"timeout"`・`steps` が 5000 で、最後の状態で |θ| ≤ 0.01・|x| ≤ 0.05。`balance` はどの状態にも絶対値 10 以下の `float` を返す
