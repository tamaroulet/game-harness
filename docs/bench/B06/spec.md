# 課題 B06：投射と狙い（launcher）

段 3 のベンチマークの課題。工廠には、この全文と判定役（`tests/launcher_judge.py`）の検証コマンドだけを渡す。

## 模型

- 玉：半径 0.02 m の球 1 個。質量 0.1 kg。自由に動ける（並進 3・回転 3）
- 床：高さ 0 の無限の平面。玉と床は接触する。接触の `solref` は (0.004, 1)（玉と床の両方の geom に付ける）。ほかは MuJoCo の既定値
- 重力：-z 向きに 9.81 m/s²。時間の刻み：0.002 s。空気抵抗なし（`density`・`viscosity` は既定の 0）
- 打ち出し：玉の中心を (0, 0, 0.02)（床に接した位置）に置き、x–z 平面の中で +x 向きに、水平からの角度 θ（度）・速さ v（m/s）の並進の速度を与える。角速度は 0
- 物理は MuJoCo 3.15.0（`mujoco` パッケージ）で計算する。積分は既定（Euler）

## 要件

- REQ-01：公開の入口。リポジトリの根の `launcher` パッケージは、次の 3 つの関数を持つ。`simulate(angle, speed, steps)` は打ち出しから `steps` 歩進め、長さ `steps` の列を返す。i 番目は i+1 歩目の後の状態で、`pos`（中心の位置 x・y・z の 3 個の float）と `vel`（並進の速度の 3 個の float）を持つ辞書。`landing(angle, speed)` は着地の点の x（float）を返す。`aim(distance, speed)` は、速さ `speed` で打ち出して x ＝ `distance` に着地する角度（度、float）を返し、見つからなければ `None` を返す
- REQ-02：入力の範囲。`angle` は 5 以上 85 以下の数、`speed` は 0.5 以上 10 以下の数、`steps` は 1 以上 20000 以下の整数、`distance` は 0 より大きい有限の数。範囲の外の値・数でない値（`bool` を含む）・整数でない `steps` には `ValueError` を投げる
- REQ-03：決定論。同じ引数で 2 回呼ぶと、3 つの関数の返り値は、すべての値がビット単位で一致する
- REQ-04：飛行。着地より前の各歩の状態で、`pos` の y と `vel` の y の絶対値は 1e-9 以下で、`pos` の x は前の歩の x 以上。返す値はすべて有限
- REQ-05：着地の点。打ち出しの位置を 0 歩目として、i−1 歩目の中心の高さ z が 0.02 より大きく、i 歩目の z が 0.02 以下になる最初の i を着地の歩とする。`landing` は、`simulate` の i−1 歩目と i 歩目の状態から z について線形に補間した x を返す。`angle` が 15 以上 75 以下で `speed` が 1 以上 8 以下のとき、`landing` と R ＝ v²·sin(2θ)/9.81 の差は、0.01·R ＋ v·cos(θ)·0.002（1 歩ぶんの水平の移動）以内
- REQ-06：床。`speed`·sin(`angle`) が 4 以下のとき、`simulate` のすべての歩で中心の高さ z は 0 以上で、着地の歩から 1000 歩後の z は 0.015 以上 0.025 以下（床の上に留まる）
- REQ-07：狙い。`speed` が 2 以上 10 以下で、`distance`·9.81/`speed`² が 0.25 以上 0.95 以下のとき、`aim` は 5 以上 45 以下の角度 θ（2 つある解のうち低いほう）を返し、`landing(θ, speed)` と `distance` の差は 0.02 m 以内
- REQ-08：届かない。`distance`·9.81/`speed`² が 1.05 を超えるとき、`aim` は `None` を返す
