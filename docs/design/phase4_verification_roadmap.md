# Phase 4 に向けた検証の基盤（提言の記録と見解）

- 状態: ロードマップの記録（実装は Phase 4 の設計で行う）
- 出どころ: 2026-09-25 のオーナーの提言（v2-smoke-04 の指示と同時）。v2 の T2・T5 の経験（game-harness#88・#93・#94）
- 前提となる原則（game-harness#94 で確立）: 希薄な前提は、状態空間の領域からの抽出（Targeted State Sampling）で起こす。系の破綻は大域の不変条件と P2P の門で捕まえる

## 1. 空虚さの診断の帰責（提言 (1)）

**提言**：前提が 1 度も成り立たない（`PROPERTY_VACUOUS`）ときは、実装役に反例の無い再試行をさせず、テストの欠陥として止める。

**見解（v2 の実測から）**：VACUOUS には 2 種類あり、帰責が逆になる。

| 種類 | 例 | 帰責 | いまの扱い |
|:--|:--|:--|:--|
| 実装に依らない | T5 のキック（開始状態と最初の手で決まる前提が、公開シードで成り立たない） | テスト（宣言・生成器） | `PROPERTY_UNSATISFIABLE`（game-harness#88）。実装を動かす前に分かり、止める |
| 実装に依る | T2 の固定（固定が起きるかは実装の Tick 次第） | 両方ありうる。v2-smoke-03 では、正しい T2 の実装でも 75% で VACUOUS（テストの欠陥）。一方、固定を実装していなければ VACUOUS は正しい知らせ | 抽出（`sampling`）で、正しい実装なら必ず前提が成り立つようにした（game-harness#94）。以後の VACUOUS は実装の知らせ |

- したがって「VACUOUS ＝ テストの欠陥」と一律に決めて止めると、固定を実装していない実装への正しい知らせまで止めてしまう
- 取り入れる形：**生成の時点で、参照モデルを「実装」として走らせ、各性質の前提が成り立つ回数を数える**（参照モデルで 0 回ならテストの欠陥、実装で 0 回なら実装の知らせ）。v2 では参照モデルが Tick を持たないので、近似のモンテカルロ（`experiments/v2/tools/lock_mc.py`・`quiet_mc.py`）で代えた。Phase 4 では、物理の参照（既知の解析解・低精度のシミュレーション）を最初から「前提の到達可能性の検査」に使う設計にする
- 帰責の線：実装に依らない空虚さ＝即時に止める（`UNSATISFIABLE`）。参照で到達できる前提の空虚さ＝実装の知らせ（`VACUOUS`）。参照でも到達できない前提＝宣言の欠陥（新しい `DEFECTIVE_PRECONDITION`）

## 2. 迷走の遮断と、証拠つきの異議の二審（提言 (2)）

**提言**：同じ失敗が続くなど迷走を検知したら、実装役に最小の再現（minimal reproducer）を出させる異議の API を用意し、異議のときだけ独立の別系統のモデルをブラインドで呼んで、テストの不備か実装の誤りかを調停させる。

**見解**：

- 既存の仕組み：実装役の `DISPUTE_TEST`（1 回だけ、One-Strike）と、ハーネスの Outer 段の連続失敗での DISPUTE（ADR-003 §3.4）。どちらも「高次のループへ回送」で、調停の手続きは無い
- v2 の実測では、迷走（T2 の A 9 回・B 6 回）の原因はテストの欠陥で、実装役はそれを異議にしなかった（VACUOUS の知らせでは、テストの不備か実装の不足かを実装役が見分けられない）。**異議を実装役の判断に任せるより、1 の到達可能性の検査で先に切り分けるほうが安い**
- 取り入れる形：迷走の検知（同じ知らせが N 回続く）で止め、実装役に最小の再現の提出を求める。調停は、(a) 参照モデルでの再実行（決定論、費用 0）を一審、(b) 独立のモデルによる判定を二審にする。二審の判定は「テストを変える」ではなく「人間の裁定に回す」までにとどめる（テストの緩和を機械に決めさせない）
- 独立性：二審のモデルには、実装役の会話・実装の中身を渡さず、仕様（宣言・参照データ）と最小の再現だけを渡す

## 3. 関係で正しさを評価する（メタモルフィック関係、提言 (3)）

**提言**：連続力学系では絶対値の比較が破綻するので、スケール不変性・時間刻みを変えたときの収束・保存則などの関係で評価する。

**見解**：

- v2 の不変条件（INV-01：ブロック数の保存）と性質（`after.X == f(before)` の形）は、すでに「状態の関係」で書いている。連続系ではこれを、許容誤差つきの関係（|E(t+Δ) − E(t)| ≤ ε(Δ)）と、2 つの走行の間の関係（Δ を半分にしたときの誤差の縮み方、座標変換・スケールへの不変性）に広げる
- 性質の宣言の式に、許容誤差（相対・絶対）と「2 つの走行を比べる」構文を足す必要がある。propgen の式の言語は整数と真偽だけなので、Phase 4 の最初の拡張点になる
- 反例の 1 行は、関係の破れの大きさ（どの関係が、どの操作列で、どれだけ破れたか）を出す形にする

## 4. Phase 4 の設計で決めること

1. 参照（解析解・低精度シミュレーション）を、到達可能性の検査と一審の調停の両方に使う設計
2. 性質の式の言語の拡張（実数・許容誤差・2 走行の関係）
3. 迷走の検知の閾値と、二審のモデルの選び方・渡すもの
