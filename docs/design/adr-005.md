## 3. これからの段（再建のタスク W-127〜W-140 は、この ADR の採択の後に台帳で作り直す）

1. ゲームのラインと実験の道具を凍結のタグに残し、main と CI から外す（D-1・D-9）
2. 試しの走行：台帳のタスク 1 件を、CI の上の公式のエージェントで実装させる（D-3）。合格の条件は次の 3 つ
   - 定額の契約のトークン（規約で使ってよいと操縦士が確かめたもの）か、API キーで認証できる。API キーなら 1 件の費用を実測する
   - 必須チェックで合否が決まり、App が `.github/` を変えた PR は通らない
   - 人が手で中継しない
3. 2 の結果で、手元の常駐ループの退役（D-3・D-6）か、走らせ役の作り直しかを決める
4. 門を、別の役が先に書く受入テストと変異の試験に寄せる（D-4、旧 W-132・W-134）
5. 横木 R4 を操縦士が決め直す（D-5）

| 指摘 | 出典 | 扱い |
