# Phase 4 自律連続開発基盤 統合計画仕様書（v3.1 改訂版）
## Contract-Driven Foundry: 3D 連続力学系・ゲーム物理の階層的自律開発アーキテクチャ

- **文書区分**: Phase 4 統合アーキテクチャ仕様書兼実行計画（Roadmap & Architecture Specification）
- **対象ドメイン**: 3D 物理シミュレーション（MuJoCo、剛体接触力学）、連続ゲーム物理エンジン
- **大目的**: 離散トイプロブレムの局所的ギブス（語彙閉包・型固定・手書きサンプラー・厳密等価）を脱却し、実務的なゲーム・3D 物理開発において**「仕様ドリフトゼロ」かつ「回帰破壊（Regression）ゼロ」の自律連続開発**を工学的に成立させる。

## 2. 具体的要素技術の定式化

### 2.1 セクター分割とモジュール境界契約（BCEG）
- **セクター（Sector）の定義**:
  全体システムを機能ドメイン（例: セクター A「剛体接触・力学系」、セクター B「キャラクター・入力制御」、セクター C「ゲームループ・描画」）に分割。
- **内部実装の完全自由化（Open Vocabulary）**:
  モジュール内での新規ファイル作成、プライベートヘルパー関数の切り出し、内部データ構造の改変、アルゴリズムの最適化を無制限に許可する。
- **公開インターフェースの SemVer 機械的強制**:
  AST 差分解析ツール（`griffe` / `cargo-semver-checks`）を Micro Gate に統合。
  - **許可（Minor/Patch）**: デフォルト引数の末尾追加（例: `step(dt, substepping=1)`）、新規公開関数の追加、戻り値の互換的拡張。
  - **即時拒絶（Major Breaking）**: 既存引数の削除、引数順序の変更、必須引数の追加。
- **P2P 回帰門**:
  過去タスクのテスト群を一切変更せずに再実行し、1 件でも失敗した場合は即時リジェクトする。

### 2.2 Simulator-as-Generator（並列ロールアウト抽出）
- **手書きサンプラーの完全廃止**:
  稀少境界状態を手動合成せず、シミュレータ（MuJoCo 等）自体の高速並列実行（100〜1,000 ワーカー）により状態空間を探索する。
- **述語トリガー（Predicate Triggers）**:
  仕様定義側は「ブール述語（Boolean Predicates）」のみを宣言する。
  - 例: `is_collision_imminent = lambda env: 0.0 < env.min_distance() < 0.05`
  - 例: `is_impact = lambda env: norm(env.contact_forces()) > F_max`
- **State Reservoir（状態貯水池）**:
  述語が True になった瞬間のシミュレータ内部状態（`mjData.qpos`, `qvel`, `act` 等のシリアライズデータ）を自動キャプチャし、PBT の `@given` 入力として供給する。これにより、**前提不成立（`PROPERTY_VACUOUS`）の発生確率をゼロ**にする。

### 2.3 力学的不変量と「オンデマンド」動的誤差包絡線
- **破綻しない力学的不変量の定式化**:
  1. **有界散逸不等式（エネルギー保存・散逸）**:
     外力なき閉鎖系において、ダンピングや非弾性衝突による力学的エネルギーの増分が許容微小積分誤差以下であること：
     $$E(t + \Delta t) - E(t) \le \epsilon_{\text{integration}}$$
  2. **内力系の重心運動量不変**:
     $$\left\| \sum m_i \mathbf{v}_i(t + \Delta t) - \sum m_i \mathbf{v}_i(t) \right\| \le C_{\text{machine}} \cdot \sum m_i \|\mathbf{v}_i\|$$
  3. **Signorini-Moreau 非貫通拘束**:
     法線間隙 $\phi(q) \ge -\delta_{\text{tol}}$ かつ 法線力 $\lambda \ge 0$、および相補性 $\phi(q) \cdot \lambda \approx 0$。
- **オンデマンド遅延評価による動的誤差包絡線**:
  高精度参照シミュレータ（$\Delta t_{\text{ref}} = \Delta t / 100$）を常時走らせる計算の無駄を排除。
  - 通常時: 安価な不変量不等式（$\Delta E \le \epsilon$）のみで高速判定。
  - アサーション境界スレスレ、または不連続な接触衝撃の瞬間のみオンデマンドで高精度参照を呼び出し、動的誤差包絡線 $\text{Tolerance}(t)$ を計算して判定する。

### 2.4 3 段階エスカレーション・フェイルセーフ（OpenAI 冷や水監査）
迷走検知（同一テスト 3 ターン連続失敗、または方針ループ）作動時：
1. **Level 1: 決定論的自動較正**:
   反例を参照モデルに流し込み、物理的に正当であれば実装バグと断定。数値感度の問題であれば、有界ノブ（`@tolerance`）の範囲内で二分探索により $\epsilon$ を自動較正（テストコード骨抜きは厳禁）。
2. **Level 2: OpenAI 外部監査・Red Teaming（冷や水フェイルセーフ）**:
   Level 1 で解決できない場合、別系統の外部モデル（OpenAI）をブラインド呼び出し。
   - 主モデル（Claude）が局所方針に固執していないかを批判的レビュー。
   - 仕様矛盾（Type 3）の有無を独立監査。
   - 迷走の原因が主モデルの認知バイアスにある場合、外部から「お前の方針は破綻している」と冷徹に軌道修正（水を差す）。
3. **Level 3: 人間エスカレーション**:
   外部監査でも調停不能な真の仕様矛盾についてのみ、20 行以内の最小再現スクリプトを添えて人間に意思決定を回送。
