3. **計画は、ねらいへの道として、書かずに置いている前提を持つ（§3 に 8 つ）。重いのは次の 3 つで、どれもリポジトリに証拠が無い。**

## 3. 問い 3：見落としている根本の問い・置いたままの前提

### P1. L8 の確立は「回る」を確かめ、「良くなる」を確かめない

- **事実：** L8 の条件は「2 周を続けて人の手なしで回し、取り込んだ改善のうち 1 件以上が保留の組でも悪くしていない」（v3:29,374）。木の req.self-improvement も「点を下げずに取り込む」サイクルが回ること（`tree.yaml:23-25`）。どちらも「点を上げる」を求めていない。
- 狙いの直りの判定は「直した対が壊した対より多く、かつ直した対が 2 以上」（承認:51）。同じ版でも段の結果は揺れる（B07 の段 2：1 回目 1/12、2 回目 12/12。v3:696）。
- **推測（付録 B）：** 効かない変更（新版と旧版が、同じ見込みで通る）でも、
  - v0 が五分で通る段を 3 段（6 対）狙えば、狙いの直りの判定を約 34% で通る。
  - B07 の F1 のように、1 回目の走りの先端からは落ちやすく（通る見込み 3 割）、2 回目の先端からは通りやすい（9 割）段を 3 段狙えば、約 20%。
  - 2 回とも落ちた段だけ（4 対、通る見込み 1 割）なら約 4%。
  - 段ごとの通る見込みは、2 回の走りからは決まらない。上の見込みは置いた値で、確かめは B-measure の領分。
- 回帰の守りは「下がらない」を見るので、効かない変更は通りやすい（開発の組は 13 段以上で、v0 は 13 と 16。保留の組は 11 段以上などで、v0 は 12。承認:53、game-harness#344）。
- **損：** L8 を「確立」と書いても、ハーネスが良くなったかは分からない。それを根拠に L7 の戻しにくい自動化を作ると、効きの分からない周期を人の手なしで回す道具になる。
- **確かめ方：** 「良くなった」と言う条件を、取り込みの判定とは別に、新版の結果を見る前に決める（例：v0 が 2 回とも落ちた段を狙いに含み、そこで直る。取り込んだ版を、別の開始の木から走らせ直しても直る）。中身は B-measure に預ける。

### P2. 物差しの余地と、面の届かない落ち

- **事実（付録 A）：** 開発の組の v0 で通った段は、1 回目 13・2 回目 16。2 回とも落ちたのは B08 の段 4（F2）と B09 の段 6（F3）。B07 の 1 回目の段 2・4・6 は F1 とその連鎖で、2 回目では通った。
- F2 は「コマンドが無いので、測って別の直しに移れない」という読み（v3:834）。コマンドを許すのは面の外（v3:360、承認:28）。
- 面の 2 つ目のつまみのうち、agy の実装役に効くのは試行の回数だけ（承認:26）。面は実質「実装役への指示の文」と「試行の回数（1〜4）」。
- 面の中で F2 に触れるのは、試行の回数を上げて、門の落ちの出力（試験の値）を手がかりに直し直す回数を増やすことだけ。保留の組では、時間の上限で止まった段が 1 つあり、門は通るとパッケージの全件をもう一度走らせる（v3:1031,1052）。試行の回数を上げると、時間の上限で止まる段が増えうる。
- **損：** 1 周目に「良くなった」を示せる余地は、開発の組で多くて 2〜3 段（推測）。揺れと同じ大きさなので、P1 と重なって、効きを見分けにくい。
- **確かめ方：** B-measure（余地と判定の力）。

### P3. 実装役の型（コマンド無しの Flash）と、比べの本番・実戦の型のずれ

- **事実：**
  - 周期が直す相手は、工廠の実装役（agy の Flash、コマンド無し）。比べの 2 条件の実装のモデルを同じにすると、会話の席が決めた（v3:59）。
  - 比べの本番は「道具をそろえる。B が周期で『コマンドを許す』を取り込んでいれば両方あり、取り込んでいなければ両方なし」（v3:390）。

- **確かめ方：** 操縦士の決め（§4 の (i)）。

## 付録 B：効かない変更が、狙いの直りの判定を通る見込みの計算

置いた前提：対ごとに、旧版と新版は同じ見込み p で、互いに独立に通る（効かない変更）。判定は承認:51 の「直した対 > 壊した対、かつ直した対 ≥ 2」。p は 2 回の走りからは決まらないので、置いた値。

```python
import itertools
def fp(ps):
    tot = 0.0
    for outs in itertools.product([(0,0),(0,1),(1,0),(1,1)], repeat=len(ps)):
        pr, fx, br = 1.0, 0, 0
        for p, (o, n) in zip(ps, outs):
            pr *= (p if o else 1-p) * (p if n else 1-p)
            fx += (o, n) == (0, 1); br += (o, n) == (1, 0)
        if fx > br and fx >= 2:
            tot += pr
    return tot
```

| 6 対 | すべて 0.3（または 0.7） | 0.293 |
| 6 対（1 回目の先端 3 対は 0.3、2 回目の先端 3 対は 0.9） | — | 0.199 |
