## 4. 新しい指摘：bench_guard の自分の控えへの偽陽性

- 事実：`harness/bench_run.py:584` が工廠の設定の控え `rundir/factory/config.json` に `line_cfg` をそのまま書き、その中の `oracles` のパスを `harness/bench_guard.py:73` の `leaks` が漏れとして拾う。W-89 では操縦士が現場で伏せて通した
- 見解：W-57 の非劣性の走行は無人で毎週走るので、手で伏せる運用は続かない。走査から外すと、本物の漏れもそのファイルでは見逃す。控えを書くときに `oracles` を伏せるほうがよい。控えを読むのは `model_problem`（`bench_run.py:775`）だけで、読むのは役ごとの model の欄なので、伏せても読みは変わらない
- 手当て：W-61 の前に入れる H ラインのタスク（下の台帳の PR の完成形）
