# 試験台の仕様（G1）

工廠ループ（What → 統合）が正しく回るかを測るための題材。ゲームではない。
題材は MuJoCo（3.15.0）の剛体 1 個と床。同じビルド・同じ入力なら決定論的に動く。

## 模型

- 床：無限の平面。高さ 0
- 箱：一辺 0.1 m の立方体 1 個。質量 1 kg。自由に動ける（並進 3・回転 3）。初めは傾きなし・静止
- 重力：-z 向きに 9.81 m/s²。時間の刻み：0.002 s
- 接触：箱と床の接触の `solref` は (0.004, 1)。そのほかは MuJoCo の既定値

## 要件

- REQ-01：公開の入口。`testbed` パッケージは `run(height, steps)` を持つ。`height` は箱の中心の初めの高さ（m、0.2 以上 2.0 以下）、`steps` は進める歩数（1 以上の整数）。返り値は長さ `steps` の列で、i 番目は i+1 歩目の後の状態。各状態は `qpos`（7 個の float：位置 x・y・z と姿勢の四元数）と `qvel`（6 個の float：並進速度と角速度）を持つ
- REQ-02：決定論。同じ `height` と `steps` で 2 回呼ぶと、返る状態の列はすべての値がビット単位で一致する
- REQ-03：床を突き抜けない。どの歩の状態も、値はすべて有限で、箱の中心の高さ（`qpos` の z）は 0.03 m 以上
- REQ-04：静止する。`height` が 1.0 で `steps` が 2000 のとき、最後の状態の並進の速さ（`qvel` の最初の 3 個のノルム）は 0.01 m/s 未満で、中心の高さは 0.04 m 以上 0.06 m 以下
