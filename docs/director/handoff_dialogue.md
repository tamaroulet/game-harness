# 会話の席（操縦士・副操縦士）の引き継ぎ

2026-10-25 会話の席（操縦士・副操縦士）作成

## 1. 役割分担と基本原則

- **操縦士（人間、L5）**:
  - 大局的な方針決定、目的の定義、権限の境界設定、環境変更の承認。
  - レビューパイプラインにおける高リスク（Tier 2）の裁定、例外エスカレーション（HIGH Risk、3 回連続失敗等）の判断。
- **副操縦士（実務役、ワーカー）**:
  - 実務の物理ゲート（§E）：一次情報確認、事前全量 grep、手元検証（fastsuite・tree・progress check 全緑実測）。
  - 権限ゲート（§B）：自律検証（コード編集・テスト実測）、外部反映・不可逆操作は操縦士承認コマンド提示。総監督が合格とした PR の自律マージ・ローカル同期。
  - 正本主義（MEM-136）：要約作文の重複・劣化を排除し、正本資料（提案書・指示書）を作成・配置して直読案内する。
  - 独断起動禁止（MEM-135）：操縦士の明示指示なき外部ジョブ起動を禁止。

## 2. 対話と承認の規律

- 確定コマンドや送信文ブロックの前には説明を置き、閉じバッククォートの後ろには一切文字を置かない。
- 未実行の承認待ちコマンドと、その成功を前提とした送信文を同一ターンに出力しない。
- 操縦士へのタスク説明は PR 単位ではなく W 単位（タスク番号と目的）で行う。

## 3. レビューと自律マージの運用

- 2026-10-25 より、審査 3 段階（機械 Gate → AI 所見 → 人間裁定）とタスク木階層を直交分離。
- 現行フェーズ 1：触れたパスから層を決める機械検査が CI に入るまでは、「総監督の検め合格 ＋ CI 全緑」で副操縦士が自律マージを実行する。
- フェーズ 2：機械検査が CI に入った後、Tier 1（低リスク）は総監督検めを挟まず完全自律マージへ移行する。
